# Channel Studio — Handoff

The project is the unified **`studio/`** React + Vite + TypeScript app (shared
shell, no page reloads), deployed via `vercel.json` (`studio/dist` is the live
site; the `api/` serverless functions stay at the repo root).

**Start here:** [`studio/HANDOFF.md`](studio/HANDOFF.md) — architecture, the
per-channel recipe, gotchas, backlog, and session logs. Then
[`studio/README.md`](studio/README.md).

> The legacy standalone single-file tools that this document used to describe
> have been retired now that the studio covers every channel. Their full docs
> and source remain in git history if ever needed for reference.
